Skill Engineering ERP - Complete Project Data Pipeline

Purpose
This file explains how the system should be used from the first customer enquiry to project closeout. It also gives sample data to enter when testing every main database area: auth/app users, customers, leads, QS, quotations, projects, sites, stock, HR, vehicles, accounting, files, client portal, and audit records.

1. Start With Demo Login
- Open /login.
- Select the role you want to test from the dropdown.
- Click Start demo.
- Use Super Admin to see all modules. Use role-specific logins to test permissions.

Recommended role tests:
- Marketing Executive: create and update leads.
- QS Engineer: prepare estimations and BOQ lines.
- Project Manager: manage projects, teams, site updates, expenses, and stock requests.
- Stock Manager: approve stock requests and create purchase orders.
- Store Keeper: receive goods and update site inventory.
- HR Manager: employees, attendance, leave, payroll.
- Vehicle Manager: vehicle assignments, fuel, meter, maintenance.
- Accountant or Finance Manager: payments, expenses, journal entries, reports.

11. End-To-End Test Checklist
1. Login as Marketing Executive and create a customer lead.
2. Move lead to under_review, then send to QS.
3. Login as QS Engineer and create estimation lines and BOQ items.
4. Generate quotation and submit it for review.
5. Login as Super Admin or Marketing Manager and mark quotation client approved.
6. Convert quotation to project.
7. Assign manager, technical officer, site team, and vehicle.
8. Add site progress updates and upload project files.
9. Raise a stock request from the project.
10. Approve the request, create a purchase order, and receive goods.
11. Confirm site inventory and stock movements.
12. Add attendance and payroll records for site staff.
13. Add project expenses and petty cash.
14. Record client payments and posted journal entries.
15. Move project to completed only when work and handover documents are done.
16. Move project to closed only when payments, expenses, inventory, payroll, and reports are reconciled.
